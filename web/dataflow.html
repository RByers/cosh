Chromium Open Source Health - Data flow

How this site's data is made: the public sources it is fetched from, the databases and files it passes through, the steps that turn one into the next, and the files the dashboards finally read. It is a maintenance map, drawn from config/dataflow.json; the design it is heading for is in docs/data-architecture.md.

Files to commit

    Nothing that reruns routinely is downstream of this.

    “Routine” steps are free and local. “Optional” steps cost Claude usage or need approval, so they run only when wanted; steps marked “after optional” have something new to do only once one of those has run. “Automatic” steps run by themselves when the files are pushed. The same plan from the command line: python3 scripts/dataflow.py plan <id>.
