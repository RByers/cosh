Chromium Open Source

Chromium is the shared engine under most of the world's browsers, built in the open by Google, Microsoft, Intel, Igalia, Opera, Samsung and many others. These dashboards look at how that project works and who sustains it, using only its public data: code review, git history, bugs and browser usage.

Dashboards

  • Value Exchange

    Does each organization put back into Chromium as much as it gets out? Compares each organization's share of the code review that changed Chromium's shared engine with its browsers' share of Chromium-based browser usage, week by week.

    Gerrit code review · Cloudflare Radar

  • Review Tone

    Is Chromium's code review getting warmer or harsher, and how do people feel about AI in review? Tracks the tone of review comments over three years, and recognises the people who give and receive the most praise.

    Gerrit code review · Claude Haiku

More dashboards are planned, drawing on Chromium's git history, its bug tracker and other public sources.
