Chromium Open Source Health

One way to reason about the health and stability of an open source project is to explore the extent a stakeholder's investment into the project is proportionate to the value it derives. When this value-exchange is far out of alignment, it may lead to a rupture in the project community. Quantifying this value exchange is generally impossible, but the Chromium open source project enables some interesting analyses. The value a Web Browser derives from its browser engine is generally proportionate to the usage of that browser (eg. through search engine ad revenue). These days the biggest cost of maintaining a large open source project is in the human cost of directing the evolution of the codebase and reviewing changes. Agentic development has made code nearly free, while increasing the value of determining what code should and shouldn't be added to the project.

This page attempts to approximate this value exchange in the Chromium Open Source project by comparing the usage of an organization's browser by the code reviews that organization contributes to the project.
