    Note on ChromeDerivative. Radar's bucket for Chromium-based browsers it can't name jumped from about 0.3% to about 11% of Chromium usage starting in 2026-W37 (on 9 September 2026). It came from every browser in proportion, Safari and Firefox included, not mostly from Chrome. It looks like Radar started labeling traffic it previously couldn't identify, possibly real Chromium-based browsers; Cloudflare hasn't explained it. The bucket stays in the denominator but is credited to no organization, so from W37 every organization's usage share is about 10% lower and its value ratio about 11% higher.
