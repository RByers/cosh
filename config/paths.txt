# Which chromium/src paths the review metrics cover. Read by cosh/paths.py.
#
#   exclude <prefix>   comments on files under <prefix> leave the headline
#   include <prefix>   ... unless a longer `include` prefix brings them back
#   area <prefix>      a directory listed at the top level of the web UI's
#                      "Review by directory" tree (no effect on scope)
#
# The longest matching include/exclude prefix wins; a path matching neither is
# included. Prefixes are directories and end in "/". The tree's top level is
# the `area` prefixes plus the top-level directories; re-included directories
# stay inside their parents.
#
# Why: chrome/, ios/, android_webview/, ash/ and chromeos/ are Google's own
# products built on Chromium (Chrome, Chrome for iOS, Android WebView and
# ChromeOS). Review there is mostly Google reviewing Google's product code, so
# it says little about who maintains the shared engine. Two chrome/
# directories hold shared platform work that other browsers build on, so they
# stay in.
#
# components/ is mostly browser features built for Chrome (autofill, signin,
# optimization_guide, enterprise...): over a year it held 16% of review
# comments, 98% of them from Google. components/viz/ (the compositor, 12%
# non-Google) and components/services/storage/ (DOM storage, the backend for
# localStorage and sessionStorage, 88% Microsoft) are engine code with real
# outside review, so they stay in.
#
# Directories with non-Google OWNERS (2026-11-06): components/surface_embed/
# (Microsoft owners, 36% Microsoft review), chrome/browser/resources/
# webnn_internals/ and chrome/browser/ui/webui/webnn_internals/ (Intel and
# Microsoft owners, the WebNN internals page) and
# the chrome/ accessibility directories, whose OWNERS include
# ui/accessibility/OWNERS with its Microsoft owners. The browser accessibility
# layer is shared platform work that other Chromium browsers contribute to.

exclude chrome/
exclude ios/
exclude android_webview/
exclude ash/
exclude chromeos/
exclude components/

include chrome/browser/web_applications/
include chrome/browser/webnn/
include components/viz/
include components/services/storage/
include components/surface_embed/
include chrome/browser/resources/webnn_internals/
include chrome/browser/ui/webui/webnn_internals/

include chrome/renderer/accessibility/
include chrome/browser/accessibility/
include chrome/browser/ash/arc/accessibility/
include chrome/browser/resources/accessibility/
include chrome/browser/ui/ash/accessibility/
include chrome/browser/ui/aura/accessibility/
include chrome/browser/ui/views/accessibility/
include chrome/browser/ui/webui/accessibility/
include chrome/test/accessibility/ax_client/

area third_party/blink/
